# Roadmap

This is an early-stage project. These are proposed maintenance priorities, not
completed features, adoption claims, or delivery commitments.

- Keep installation, CLI smoke checks, and existing regression tests reproducible in CI.
- Collect consented, anonymized examples of incorrect cavities and blocked openings.
- Expand regression coverage for geometry edge cases reported by users.
- Improve case-format documentation and diagnostics based on reproducible feedback.
- Validate NX journals on additional versions when maintainers have access to them.

Current evidence: [synthetic demo](examples/README.md), [NX validation notes](VALIDATION.md).
The project does not currently offer automatic arbitrary-drawing-to-CAD reconstruction.
